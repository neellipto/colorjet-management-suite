# COLORJET ERP Native Android V2.0.0

## Rebuild scope

- Expo and React Native are not used.
- WebView and unavailable server login are removed from the main ERP workflow.
- The existing native Android project, package ID `com.colorjetbd.erp`, original launcher artwork, signing workflow and background location service are preserved.
- No default login ID or hardcoded password is included.

## Working offline modules

- First-run secure Owner account setup
- PBKDF2 password hashing with random salt
- Owner login, session and password change
- Owner KPI dashboard
- Customers CRUD and CSV export
- Products and stock CRUD, stock value and low-stock KPI
- Office tasks CRUD and status workflow
- Service tickets CRUD and status workflow
- Engineer duty/background route tracking
- Private on-device SQLite database

## Version

- Version name: `2.0.0`
- Version code: `12`
- Minimum Android: 7.0 (API 24)
- Target Android SDK: 35

## Data note

This build is local-first because no live COLORJET ERP backend was available in the supplied package. Records remain in Android private storage. Export module data to CSV before clearing app data or uninstalling.
